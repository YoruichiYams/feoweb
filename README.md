# Официальный сайт отеля «Сердце Города» (г. Феодосия, Крым)

Современный, адаптивный веб-сайт отеля с независимой системой онлайн-бронирования, личным кабинетом гостя и полнофункциональной административной панелью с шахматкой номерного фонда (интерфейс в стилистике TravelLine Avenue theme).

---

## 📍 Локационные данные
- **Отель:** «Сердце Города»
- **Адрес:** Республика Крым, г. Феодосия, ул. Победы, д. 36/1
- **Ориентиры:** 10–12 минут пешком до Черного моря, набережной Десантников и Национальной картинной галереи им. И.К. Айвазовского. Удобный заезд с трассы «Таврида» и Крымского моста, 5 минут от ж/д вокзала «Феодосия».
- **Контакты:** +7 (995) 171-16-64 | booking@serdtse-feodosia.ru
- **Стойка регистрации:** 24/7 (круглосуточно)

---

## 🛠 Технологический стек
1. **Frontend:** React 19, TypeScript, Vite.
2. **Стилизация:** Исключительно **Vanilla CSS** (CSS Custom Properties, Flexbox/Grid, CSS Modules, плавные микроанимации и backdrop-filter).
3. **Backend / API:** Cloudflare Pages Functions в каталоге `/functions/api/[[route]].ts` на базе фреймворка **Hono** (`hono`).
4. **База данных:** Cloudflare D1 (SQLite) со схемой миграции `migrations/0001_init.sql`.
5. **Иконки:** Lucide Icons.

## 🏨 Структура и возможности системы

### 1. Публичный сайт
- **Header:** Информационный бар с точным адресом в Феодосии, быстрый доступ в панель отеля и личный кабинет, переключатель языка (RU/EN), адаптивное бургер-меню и кнопка быстрого бронирования.
- **Hero-секция:** Слайдер интерьеров с автопрокруткой, плавающий виджет репутации (`TL: Reputation` 9.5 / 10 на основе 495+ отзывов) и горизонтальная панель поиска свободных номеров.
- **О нас:** Презентация отеля, исторический контекст Феодосии, 17 комфортабельных номеров, охраняемая закрытая парковка во дворе.
- **Каталог номеров (9 категорий):**
  1. Стандарт двухместный
  2. Студия витражная
  3. Люкс 2-х комнатный
  4. Люкс 3-х комнатный
  5. 3-х местный стандарт
  6. Апарт-студия
  7. Однокомнатная квартира
  8. Студия с кухней
  9. Стандарт на 2-х
- **Спецпредложения:** Основной тариф (прямая выгода на сайте), Длительное проживание (скидка 15% + парковка), Семейный вояж.
- **Услуги:** Интерактивный аккордеон (питомцы до/от 3 кг, фермерские завтраки, прачечная, халаты, кухни, парковка).
- **Отзывы:** Агрегированные оценки с Яндекс Карт (5.0), 2ГИС (4.9) и 101Hotels (5.0), слайдер и модальное окно добавления отзыва.
- **Фотогалерея:** Категории (Номера, Интерьер, Территория и море) с полноэкранным Lightbox-просмотром.
- **Контакты и интерактивная карта:** Геометка ул. Победы 36/1, кнопки вызова в один клик (телефон, WhatsApp, Telegram), подробные маршруты на авто, от ж/д вокзала и автовокзала.
- **Footer:** Реквизиты ИП, режим работы, копирайт и ссылки на юридические документы.

### 2. Система онлайн-бронирования (`/booking`)
- **Шаг 1:** Фильтр дат и количества гостей (динамическая проверка свободных номеров в D1 без пересечений).
- **Шаг 2:** Выбор категории, выбор тарифа (Базовый или «С завтраком») и сопутствующих услуг.
- **Шаг 3:** Ввод данных гостя и **строгий юридический комплаенс**:
  - Чекбокс согласия на обработку ПДн по 152-ФЗ (не предвыбран).
  - Чекбокс принятия Публичной оферты и Правил проживания/аннуляции по ПП РФ № 1853 (не предвыбран).
- **Шаг 4:** Генерация уникального номера брони (`SG-2026-XXXX`), печать ваучера гостя (`window.print()`), Telegram-уведомление администратору и сохранение в базу данных.

### 3. Личный кабинет гостя (`/guest-account`)
- Быстрый поиск по номеру бронирования и телефону / фамилии.
- Вход по логину/паролю и соцсетям (VK, Tinkoff, Sber, Alfa).
- Отображение активного бронирования и статуса.
- **Интеллектуальная отмена бронирования:** автоматический расчет возврата по Постановлению Правительства РФ № 1853 (бесплатная отмена за 48 часов до заезда; удержание не более 1 суток фактического простоя при поздней аннуляции).
- Блок программы лояльности с бонусными баллами.

### 4. Панель управления администратора (`/admin`)
- Защищенный вход (по умолчанию `admin` / `admin123`).
- **Дашборд:** Текущая загрузка отеля (%), заезды сегодня, выезды сегодня, суммарная выручка.
- **Шахматка (Calendar Timeline):** 14-дневная интерактивная шахматка номерного фонда с визуализацией занятости по каждому номеру, изменением статусов и быстрым созданием брони от стойки.
- **Управление номерами:** Редактирование базовых цен, вместимости и статусов доступности.
- **Отзывы:** Модерация и управление отображением отзывов.
- **Настройки:** Управление контактами, реквизитами, расчетным часом (14:00/12:00) и привязкой Telegram Bot ID.

### 5. Юридический блок и Cookie Consent
- `/privacy-policy` — Политика обработки ПДн по 152-ФЗ.
- `/terms-of-service` — Публичная оферта по ст. 437 ГК РФ и ПП РФ № 1853.
- `/refund-policy` — Правила аннуляции и возврата по ст. 32 ЗоЗПП РФ.
- `/cookie-policy` — Политика использования файлов cookie.
- **Cookie Consent Banner:** Фиксированная плашка с кнопками «Принять все» и «Настроить», модальное окно с 4 переключателями категорий (Строго необходимые, Аналитика, Функциональные, Рекламные) и сохранением выбора в `localStorage`.

## 🚀 Запуск и деплой

### Локальная разработка:
```bash
npm install
npm run dev
```
Сайт доступен по адресу `http://localhost:5173/`. В локальном режиме система автоматически поддерживает автономное хранение бронирований, номеров и настроек в `localStorage`, поэтому все функции (бронирование, личный кабинет, админка) работают на 100% без внешних зависимостей.

### Сборка проекта:
```bash
npm run build
```
Генерирует оптимизированный бандл в директорию `dist/` и функции в `functions/`.

### Деплой на Cloudflare Pages с базой D1:
1. Создать базу данных D1:
   ```bash
   npx wrangler d1 create hotel_db
   ```
2. Применить миграции:
   ```bash
   npx wrangler d1 migrations apply hotel_db --remote
   ```
3. Опубликовать проект в Cloudflare Pages:
   ```bash
   npx wrangler pages deploy dist
   ```
